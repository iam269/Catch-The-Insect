# Catch The Insect 🦟🐛🕷️🐜

A fun and challenging web-based game where you try to catch flying insects before time runs out! 🕹️

## Live Demo 🌐
Play the game online: [https://itsiamdev.github.io/Catch-The-Insect/](https://itsiamdev.github.io/Catch-The-Insect/)

## How to Play 🎮
1. Click "Play Game" to start.
2. Choose your favorite insect to hunt.
3. Click on the insects as they appear on the screen.
4. Score points for each catch! 🏆
5. See the message when you reach 20 points. 😎

## Features ✨
- Multiple insect types: Fly, Mosquito, Spider, Roach.
- Real-time timer ⏱️
- Score tracking 📊
- Responsive design 📱

## Technologies Used 🛠️
- HTML5
- CSS3
- JavaScript (ES6)

## Installation 🚀
1. Clone the repository.
2. Open `index.html` in your browser.
3. Enjoy the game!

Have fun catching those bugs! 🐞
